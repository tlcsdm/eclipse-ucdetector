Introduction

UCDetector (Unnecessary Code Detector - pronounced "You See Detector") is an Eclipse plug-in that finds unnecessary public Java code and reports it in the Problems view.

UCDetector can report:

  • Unnecessary (dead) code
  • Members whose visibility can be reduced
  • Fields or methods that can be declared final
  • Cyclic dependencies between classes

This repository is a fork of the original UCDetector project on SourceForge and targets Java 17 with Eclipse 2024-06 or newer.
