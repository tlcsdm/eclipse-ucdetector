Custom Detectors

UCDetector can be extended with custom detectors. The companion plug-in com.tlcsdm.eclipse.ucdetector.additional in this repository is a working example.

Use that example as a template when you need to:

  • Add a new action and contribute it through org.eclipse.ui.commands, org.eclipse.ui.handlers and org.eclipse.ui.menus.
  • Implement a custom iterator that visits Java elements and creates markers.
  • Declare new marker types and annotation specifications in plugin.xml.
  • Externalize labels in plugin.properties.
