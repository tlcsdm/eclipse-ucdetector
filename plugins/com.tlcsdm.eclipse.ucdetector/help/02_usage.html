Usage

Install the plug-in

  1. Open Help > Install New Software... in Eclipse.
  2. Add the update site https://raw.githubusercontent.com/tlcsdm/eclipse-ucdetector/update_site/.
  3. Select UCDetector, finish the wizard and restart Eclipse.

Run a detection

  1. In the Package Explorer or Project Explorer, right-click a Java project, source folder, package, type or working set.
  2. Open the UCDetector submenu.
  3. Choose one of the available actions:
    • Detect unnecessary code
    • Clean UCDetector markers
    • Count references
    • Detect cycles

Review results

UCDetector creates markers in the Eclipse Problems view. Double-click a marker to jump to the relevant source. Many findings also provide a Quick Fix via Ctrl+1.

Preferences

Open Window > Preferences > UCDetector to configure detection modes, filters and markers.

Headless mode

UCDetector can also run as the Eclipse application com.tlcsdm.eclipse.ucdetector.detect. See the repository's launches/ folder for ready-to-use launch configurations.
