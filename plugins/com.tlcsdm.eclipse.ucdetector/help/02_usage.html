Usage

Install the plug-in

  1. Open Help > Install New Software... in Eclipse.
  2. Add the update site https://raw.githubusercontent.com/tlcsdm/eclipse-ucdetector/update_site/.
  3. Select UCDetector, finish the wizard and restart Eclipse.

Run a detection

  1. In the Package Explorer or Project Explorer, right-click a Java project, source folder, package, type or working set.
  2. Open the UCDetector submenu.
  3. Choose one of the available actions described below.

Main UI components

Package Explorer / Project Explorer
Select the Java project, source folder, package, type or working set that UCDetector should analyze.
UCDetector submenu
The entry point for the plug-in's commands in the context menu.
Detect unnecessary code
Runs the main analysis and reports dead code, reducible visibility and members that can be declared final.
Clean markers
Removes UCDetector markers from the selected scope when you want to rerun the analysis from a clean state.
Count elements
Counts the Java elements that would be considered by UCDetector for the current selection.
Detect cycles
Searches for cyclic class dependencies and opens the Cycle View for inspection.
Problems view
Shows UCDetector markers. Double-click a marker to jump to the affected source location.
Quick Fix (Ctrl+1)
Available for many marker types so you can apply the suggested fix directly from the editor.
Preferences page
Window > Preferences > UCDetector configures filters, detection modes, markers and logging.
UCDetector Console
Displays plug-in log output when console logging is enabled in the preferences.

Review results

UCDetector creates markers in the Eclipse Problems view. Double-click a marker to jump to the relevant source. Many findings also provide a Quick Fix via Ctrl+1.

Preferences

Open Window > Preferences > UCDetector to configure detection modes, filters and markers.

Headless mode

UCDetector can also run as the Eclipse application com.tlcsdm.eclipse.ucdetector.detect. See Headless Usage for the command line workflow and the repository's launches/ folder for a ready-to-use Eclipse launch configuration.
