Headless Usage

UCDetector can run without the Eclipse UI by starting the application com.tlcsdm.eclipse.ucdetector.detect. This is useful for CI jobs or scripted workspace checks.

Command line example

java -Xmx2048m -jar <ECLIPSE_HOME>/plugins/org.eclipse.equinox.launcher_<version>.jar \
  -clean -data <WORKSPACE> \
  -application com.tlcsdm.eclipse.ucdetector.detect \
  -ucd.options <path-to>/ucdetector.options

The repository's launches/UCDetector-run-headless.launch file uses the same application id and is the easiest way to debug the headless flow inside Eclipse.

Options file

The -ucd.options argument points to a properties file. It can contain normal UCDetector preferences together with these headless-specific keys:

  • com.tlcsdm.eclipse.ucdetector.internal.headless.buildType - FULL_BUILD or INCREMENTAL_BUILD.
  • com.tlcsdm.eclipse.ucdetector.internal.headless.targetPlatformFile - optional target definition file.
  • com.tlcsdm.eclipse.ucdetector.internal.headless.report - eachproject or single.
  • com.tlcsdm.eclipse.ucdetector.internal.headless.resourcesToIterate - comma-separated workspace resources to limit the scope.

Minimal example

com.tlcsdm.eclipse.ucdetector.log.level = INFO
com.tlcsdm.eclipse.ucdetector.internal.headless.buildType = FULL_BUILD
com.tlcsdm.eclipse.ucdetector.internal.headless.report = eachproject
# com.tlcsdm.eclipse.ucdetector.internal.headless.resourcesToIterate = my.project/src/main

Interactive console commands

While the headless application is running, you can type commands in the console:

  • h or ? - print the help text again
  • s - stop or continue the monitor
  • e - cancel and exit
