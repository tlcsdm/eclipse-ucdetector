UCDetector

UCDetector (Unnecessary Code Detector - pronounced "You See Detector") is an Eclipse plug-in that finds unnecessary (dead) public Java code. It produces markers in the Eclipse Problems view for:

  • Unnecessary (dead) code
  • Code where the visibility could be reduced to protected, default or private
  • Methods or fields that can be declared final

This fork is based on the original UCDetector project on SourceForge and targets Java 17 and Eclipse 2024-06 or newer.
