Writing your own UCDetector detector

UCDetector can be extended with custom detectors. The companion plug-in com.tlcsdm.eclipse.ucdetector.additional in this repository is a working example showing how to:

  • Add a new Action and contribute it via the org.eclipse.ui.popupMenus extension point.
  • Implement a custom Iterator that walks the relevant Java elements and creates markers using AdditionalIterator.createMarker().
  • Declare new marker types via org.eclipse.core.resources.markers, org.eclipse.ui.editors.annotationTypes and org.eclipse.ui.editors.markerAnnotationSpecification.
  • Externalize labels in plugin.properties.

Use the com.tlcsdm.eclipse.ucdetector.additional module as a template when adding your own detectors.
