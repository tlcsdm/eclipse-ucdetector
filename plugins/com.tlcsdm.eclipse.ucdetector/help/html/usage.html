Getting started with UCDetector

Installation

  1. In Eclipse, open Help > Install New Software...
  2. Add the update site https://raw.githubusercontent.com/tlcsdm/eclipse-ucdetector/update_site/.
  3. Select the UCDetector feature, finish the wizard and restart Eclipse.

Running a detection

  1. In the Package Explorer or Project Explorer, right-click a Java project, source folder, package, type or working set.
  2. Choose UCDetector from the context menu.
  3. Pick one of the available actions:
    • Detect unnecessary code - reports dead code, reducible visibility and fields/methods that can be final.
    • Clean UCDetector markers - removes the markers UCDetector created.
    • Count references - reports the number of references for the selected Java elements.
    • Detect cycles - finds cyclic class dependencies.

Reviewing the results

UCDetector reports its findings as markers in the Eclipse Problems view. Double-click a marker to jump to the affected code. Many findings come with a Quick Fix (Ctrl+1) that can apply the suggested change.

Configuration

The detection modes and filters are configured under Window > Preferences > UCDetector. There you can choose which checks to run, what to ignore and which markers to create.

Headless mode

UCDetector can also run from the command line as an Eclipse application using the application id com.tlcsdm.eclipse.ucdetector.detect. See the launch configurations under the repository's launches/ folder for an example setup.
