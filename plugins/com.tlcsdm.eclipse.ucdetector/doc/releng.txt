== UCDetector release engineering
Steps to create new UCDetector version.


=== Clean up code
* run PDE tools on MANIFEST.MF
* run source ... popup menus on UCDetector project
* check TODO's in code
* check build.properties
* check MANIFEST.MF
* update version number in: /com.tlcsdm.eclipse.ucdetector/META-INF/MANIFEST.MF
* search old version number "1.0.0" in files
* spell check
* check UCDetector Code with: PMD, CPD, findbugs, http://www.enerjy.com
* Update CHANGES.txt from bug/feature list from sourceforge


=== HELP
* check screenshots
* add new features, bug fixes to help
* update com.tlcsdm.eclipse.ucdetector.website\xml\releases.xml from
         com.tlcsdm.eclipse.ucdetector/doc/CHANGES.txt
* check help


=== Create
* use eclipse 4.2 and java 1.6:
# $ECLIPSE_HOME/eclipse.ini 
-vm
/opt/jdk1.6.0_23/bin/java
* Create ucd.jar, source.jar, additional: /com.tlcsdm.eclipse.ucdetector/build/UCDetector-build.launch -> run as "UCDetector-build"
** check ucdetector.jar (VERSION.TXT file must contain eclipse 4.2 and java 1.6)
** check source.jar (missing files? additional files?)


=== Smoke test
* deploy com.tlcsdm.eclipse.ucdetector.jar and com.tlcsdm.eclipse.ucdetector.additional.jar to a CLEAN eclipse 4.2, java6
** Run UCDetector detecting code in com.tlcsdm.eclipse.ucdetector.example/examples with settings: release_settings.properties
* deploy com.tlcsdm.eclipse.ucdetector.jar and com.tlcsdm.eclipse.ucdetector.additional.jar to "Eclipse IDE for Java Developers"
	   
** [Run UCDetector in: jEdit, JUnit]
** run UCDetector with: change warn limit to 2
** Apply QuickFixes to QuickFixExample
* check: Help/about Eclipse Platform/Plugin Details
* check help
* check about dialog entry
* UCDetector setting: All warning, simple class name
* count
* delete markers
* cycle detect: /com.tlcsdm.eclipse.ucdetector.example/cycle
* check UCDMarker: /com.tlcsdm.eclipse.ucdetector.example/example
** check html report
** Add version number to html report: <title> tag: version 1.0.0
** [Commit html/xml report to: /com.tlcsdm.eclipse.ucdetector.releases/reports]


=== [Run headless]
* Put jar in        : ~/ucdetector/ucdetector-headless/eclipse/dropins
* Unzip ant files to: ~/ucdetector/ucdetector-headless/eclipse/ant
* Run               : ~/ucdetector/ucdetector-headless/ant> ant


=== Sourceforge
* Firefox
* https://sourceforge.net/project/admin/?group_id=219599
* Firefox! Files / Add folder "1.2.3" / Add file
* Upload
** com.tlcsdm.eclipse.ucdetector_x.y.z.jar         - Default Download For: Select all
** com.tlcsdm.eclipse.ucdetector.source_x.y.z.zip 
** README.TXT                       - Only text of last version!
* Make last jar default download: Files -> ... -> com.tlcsdm.eclipse.ucdetector_x.y.z.jar -> i icon -> Select All -> Save


=== update site (http://ucdetector.sourceforge.net/update):
* Update Version number
* /com.tlcsdm.eclipse.ucdetector.site/site.xml
** click: synchronize, build all
* Delete old /com.tlcsdm.eclipse.ucdetector.site/features
* Delete old /com.tlcsdm.eclipse.ucdetector.site/plugins
* Copy "original" plugin from /com.tlcsdm.eclipse.ucdetector/build/output/plugins to /com.tlcsdm.eclipse.ucdetector.site/plugins
* ant send -d
** when there are problems in eclipse, use command line
* check if update site works: http://ucdetector.sourceforge.net/update

=== Add artifacts to: com.tlcsdm.eclipse.ucdetector.releases
* plugins
* features
* source
